# 🖱️ Thumbnail Click Probability Tester

A machine learning web application that predicts whether a user will click on a video thumbnail based on its brightness and text length using Logistic Regression.

🔗 **Live App Demo:** [Thumbnail Click Probability Checker]([link](https://ml-project03-thumbnail-click-probability.streamlit.app/))

## 🧠 Concepts Covered
* **Logistic Regression:** Training a Binary classifier to output probabilities (0 to 1) instead of absolute continuous numbers.
* **Binary Classification:** Categorizing data into two distinct groups (Clicked vs. Ignored).
* **Sigmoid Curve Visualization:** Plotting the exact mathematical S-curve that Logistic Regression uses to calculate probability thresholds.

## 🛠️ Tech Stack
* **Language:** Python
* **ML Libraries:** Scikit-Learn
* **Data Processing:** Pandas, NumPy
* **Visualization:** Matplotlib
* **Deployment & UI:** Streamlit
